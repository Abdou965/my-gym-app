# IronCore — نظام التدريب الشخصي (Python Edition)

تطبيق ويب محلي لتتبع تمارين كمال الأجسام، مبني على **FastAPI + SQLite + HTMX**،
بدون أي تكلفة أو اشتراك، ويعمل بالكامل من هاتفك على شبكة الواي فاي المنزلية.

## المميزات

- 4 برامج تدريب جاهزة: PPL / Upper-Lower / Bro Split / Full Body
- محرك **التدرج المضاعف (Double Progression)** يقترح تلقائياً متى ترفع الوزن
- حساب **1RM** بمعادلة Brzycki
- فلترة **المجموعات الفعالة** (RIR ≤ 3) لحساب الحجم الأسبوعي الحقيقي لكل عضلة
- تمارين مخصصة، متتبع وزن الجسم، سجل كامل لكل جلسة
- تحديثات فورية بدون إعادة تحميل الصفحة (HTMX)
- قابل للتثبيت كتطبيق (PWA) على شاشة الهاتف الرئيسية

## التشغيل (خطوة بخطوة)

### 1. تثبيت المتطلبات

يتطلب Python 3.11 أو أحدث.

```bash
cd ironcore-app
python -m venv venv
source venv/bin/activate        # على Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. تشغيل الخادم

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

عند أول تشغيل، سيُنشئ التطبيق تلقائياً ملف `ironcore.db` (قاعدة بيانات SQLite)
ويملأه بالبرامج والتمارين الافتراضية — لا حاجة لأي إعداد يدوي.

### 3. الوصول من الحاسوب

افتح المتصفح على: **http://localhost:8000**

### 4. الوصول من الهاتف (نفس شبكة الواي فاي)

1. اعرف عنوان IP المحلي لحاسوبك:
   - Windows: `ipconfig` (ابحث عن IPv4 Address)
   - Mac/Linux: `ifconfig` أو `ip addr` (ابحث عن inet)
   - مثال: `192.168.1.5`
2. من متصفح الهاتف، افتح: `http://192.168.1.5:8000`
3. تأكد من أن الحاسوب والهاتف على **نفس شبكة الواي فاي**.

### 5. تثبيت كتطبيق (PWA) على الهاتف

**Android (Chrome):** القائمة (⋮) ← "إضافة إلى الشاشة الرئيسية"
**iPhone (Safari):** زر المشاركة 📤 ← "إضافة إلى الشاشة الرئيسية"

## المحرك العلمي (`app/logic.py`)

### 1RM — معادلة Brzycki
```
1RM = الوزن × 36 / (37 - التكرارات)
```

### التدرج المضاعف (Double Progression)
لكل تمرين نطاق تكرارات مستهدف (مثلاً 6–8). القاعدة:
- إذا وصلت لكل المجموعات الفعالة إلى الحد الأعلى للتكرارات **وكان RIR ≤ 2** →
  يُقترح رفع الوزن في الجلسة القادمة بمقدار `increment_weight` الخاص بالتمرين.
- إن لم تصل → يبقى الوزن كما هو مع التركيز على زيادة التكرارات أولاً.

### المجموعات الفعالة (Effective Sets)
مجموعة تُحتسب في الحجم الأسبوعي فقط إذا كان **RIR ≤ 3** (أي قريبة من الفشل)،
فتُستبعد مجموعات الإحماء تلقائياً من إحصائية "الحجم الفعّال لكل عضلة".

## ملاحظات

- قاعدة البيانات ملف واحد (`ironcore.db`) — يمكن نسخه احتياطياً بسهولة.
- لا حاجة لإنترنت بعد التشغيل الأول (باستثناء تحميل الخطوط من Google Fonts وHTMX من CDN
  في المرة الأولى؛ يمكن استبدالها بنسخ محلية لعمل offline كامل إن رغبت).
- لتشغيل التطبيق دائماً في الخلفية على جهاز منزلي، استخدم `pm2` أو `systemd` أو ببساطة
  شغّله داخل `screen`/`tmux`.
